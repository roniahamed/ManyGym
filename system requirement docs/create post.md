1. Create Post
Clicking the box opens a composer with:
Field / Action
Behaviour
Post Text
Multiline text box: “Share an update from your gym…”
Add Photos / Videos
Upload multiple photos, videos, or a mixture
Media Preview
Preview attachments, remove them, and drag to reorder
privacy
Public / Gym members only
Publish
Publish immediately

 

Here are some points:
A post can contain only text. But when uploading Media file, text is optional (Just like Facebook)
Each media file will have orders to view. Admin can re-arrange order by dragging the media files from the Media preview window
Each media file of a post will have unique link, just like each post will have (embedded link)
The video's thumbnail will be auto generated by default. But admin can change the thumbnail later by clicking on Edit button of a video


Media formats
Only accepts:
Picture
Video

Picture formats:
Jpg
Jpeg
Png
Webp

Video format:
MP4
MOV


Size Limitations
Max 10 mb for each picture size
Max 200 mb for each video size
