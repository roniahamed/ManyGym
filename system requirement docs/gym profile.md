Gym name: String
Profile Picture: Image (max 1)
Cover photo: Image (max 1)
Short Description: String (minimum 120 characters)

About Gym type, there will be two fields: Primary Gym type (Single select dropdown), Secondary Gym type (Single select dropdown). But these fields' values will be selected from the same options/list.

Location

Same like Afrobeutic.

→ Search for a gym name or address.
→ Select a result to position the map pin.
→ Adjust the pin to the gym’s entrance.
→ Automatically fill the address fields.
→ Review and save.

Only change is, keep the “address” field editable though it will be automatically captured by the live location pin point.
